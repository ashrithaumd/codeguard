CodeGuard is a GitHub App that reviews pull requests: it runs real security and lint scanners, has an LLM judge each finding in context, and posts what survives as review comments — with a one-click fix where it can write one.

  1. Install the CodeGuard GitHub App on a repository It needs read access to code and pull requests, and write access to checks and pull request comments.
  2. Open or update a pull request Reviews run on opened and on every push to an open pull request.
  3. The review appears here Optionally add a .codeguard.yml to the default branch to change which severities block the check.
